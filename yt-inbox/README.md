# yt-inbox: tu wrzucasz nagrania lektora

1. Wklej tekst z powiadomienia (albo z pliku `lektor.txt`) do ElevenLabs, model Eleven v4. Tagów `[long pause]` nie usuwaj.
   - Ukryta Lekcja: głos klon „yooyo”.
   - Nie wiem ale bangla: głos „Oscar – Energetic, Direct”.
2. Pobierz MP3 (nazwę zostaw taką, jaką daje ElevenLabs).
3. Tutaj na GitHubie: **Add file → Upload files** → przeciągnij MP3 → **Commit changes**.

Automat sprawdza ten folder codziennie ok. 10:20, robi cały odcinek z 3 Shortsami i planuje go w Metricool z 48-godzinnym oknem na weto. Pliki zostają tutaj jako archiwum. Nie usuwaj tego README.
